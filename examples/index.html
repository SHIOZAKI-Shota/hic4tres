hic4tres デモ

Chrome / Chromium 157以降（HTML-in-Canvas対応）で開いてください。GitHub / README

立方体は、入力欄以外の場所をドラッグすると中心を軸に回せます。離すと惰性でしばらく回ります。

このページはViteでビルドして使います。pnpm example:buildを実行してexamples/dist/を開くか、pnpm exampleで開発サーバーを起動してください。

立方体

各面は本物のDOMです。フォームに入力したり、ボタンを押したりできます。

立方体（WebGPU）

同じ立方体をWebGPURendererで描いたものです。

立方体（CSS3DRendererフォールバック）

HTML-in-Canvasに対応していないブラウザ向けのフォールバックで描いたものです。面はCSSの3D変形でcanvasに重ねたDOMなので、ライティングや遮蔽は効きません。非対応ブラウザでは、上の2つも自動でこの表示になります。

遮蔽

柱に隠れた部分を押しても、ボタンや入力欄は反応しません。ボタンを押している間は面が黄色に、柱を押している間は柱が黒になります。

THREE.HTMLTextureとの比較

左はthree.js r187のHTMLTexture、右はhic4tresです。HTMLTextureは正式版のAPIに対応していないため、真っ黒になります。

素直に転送したときの問題

1は上下が逆さまで色が薄く、2は上下を直しても色が薄いままです。3のhic4tresはDOMと同じ色になります。右下の四角はthreeが描いた#0038ffの色見本です。

TresJS + Vue

Vueのフォームを貼った立方体です。入力した名前が右面にリアクティブに表示されます。

TresJS + Vue（WebGPU）

TresJS + Vue（CSS3DRendererフォールバック）

同じVueのフォームを、HTML-in-Canvas非対応ブラウザ向けのフォールバックで描いたものです。
